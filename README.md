## 📌 About

This repository contains **six C++ programming tasks** I completed during my internship with
**AICP Online**. Each task models a small real-world scenario and focuses on the fundamentals every
programmer needs: **loops, conditions, arrays, input validation and clean step-by-step logic**.

---

## 🧩 The Tasks

| # | File | Scenario | Concepts Practised |
|:-:|---|---|---|
| 1 | [`task_1.cpp`](task_1.cpp) | **Pupil Weight Tracker:** record pupils' weights on the first and last day and report the difference | Arrays, input validation (0–300 kg), loops |
| 2 | [`task_2.cpp`](task_2.cpp) | **Senior Citizens' Outing:** plan a trip for 10–36 people, calculate coach hire and meal costs, and record participants | Range checks, cost calculation, conditions |
| 3 | [`task_3.cpp`](task_3.cpp) | **Dairy Farm Milk Yield:** log each cow's morning and evening yield for a week, then report the herd's total and the average per cow | 2D data, validation, weekly statistics |
| 4 | [`task_4.cpp`](task_4.cpp) | **Auction Manager:** set up items with reserve prices, accept buyer bids and track the highest bid | Functions, parallel arrays, bidding rules |
| 5 | [`task_5.cpp`](task_5.cpp) | **Car Park Payment:** calculate parking charges by day and arrival time, with discounts for valid parking numbers | Validation, discount logic, functions |
| 6 | [`task_6.cpp`](task_6.cpp) | **Wildlife Park Tickets:** one-day and two-day ticket options plus extra attractions, with a total cost per booking | Lookup tables, totals, menus |

---

## 🚀 Run Any Task

You only need a C++ compiler (g++, clang or MSVC).

```bash
git clone https://github.com/fewgets/AICP-Project.git
cd AICP-Project

# compile and run, e.g. task 1
g++ task_1.cpp -o task_1
./task_1          # on Windows: task_1.exe
```

Every program is interactive. Follow the prompts in the terminal.
